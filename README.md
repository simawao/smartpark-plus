# 📖 Proje Hakkında

KO-PARK, belediyelerin park ve yeşil alan yönetim süreçlerini dijitalleştirmek amacıyla geliştirilmiş bir **Akıllı Şehir Yönetim Sistemi** prototipidir.

Sistem sayesinde;

- 🌳 Park envanteri yönetilebilir.
- 🔧 Bakım süreçleri planlanabilir.
- 👷 Personel ve görev dağılımı yapılabilir.
- 🚨 Arızalar takip edilebilir.
- 📢 Vatandaş bildirimleri yönetilebilir.
- 📍 Parklar harita üzerinden görüntülenebilir.
- 📊 Raporlar oluşturulabilir.
- 📅 Etkinlikler planlanabilir.

> **Not:** Bu proje eğitim ve yazılım mühendisliği çalışmaları kapsamında geliştirilmiş bir prototiptir.
